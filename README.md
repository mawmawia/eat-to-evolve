# Eat to Evolve 🐜 → 🪳

Real-time multiplayer.io survival game. Spawn as an ant, eat, grow, evolve to cockroach.

### 🎮 How to Play
Desktop: WASD | Mobile: Joystick | Eat to grow | Lv10 = Evolve | 20% bigger = Eat players

### 🚀 Run Locally
`npm install` then `npm run dev`

### ☁️ Deploy
1. Push to Github
2. Import to Vercel. 1 Click Deploy. Done.
